# PC3000-6E Troubleshooting Assistant — versi 4

## Fokus versi ini
- Beranda fokus pada Troubleshooting by Trouble Code.
- Cari berdasarkan nomor Message, nama pesan, atau komponen seperti B15/B17.
- Pilih pesan untuk melihat halaman manual terkait dan referensi halaman cetak/PDF.
- Checklist kerja, catatan hasil ukur, tindakan, dan ekspor laporan teks.
- Konten prosedur berasal dari ekstraksi teks Shop Manual yang diberikan; diagram dan tabel kompleks tetap harus diverifikasi pada PDF asli.

## Upload ke GitHub Pages dari Android
1. Ekstrak ZIP ini.
2. Buka repo GitHub yang sudah ada, lalu Add file > Upload files.
3. Unggah semua file di dalam folder ini ke root repo (bukan ZIP, bukan folder pembungkus): `index.html`, `app.js`, `style.css`, `trouble_codes.json`, `README_ID.md`.
4. Commit changes.
5. Tunggu beberapa menit lalu refresh website. Bila tampilan lama, lakukan refresh ulang atau buka tab samaran.

## Batasan penting
Versi ini mengindeks pesan error yang terdeteksi di bagian Troubleshooting by Trouble Code dan mengelompokkan halaman manual terkait. Ini bukan sistem diagnosis otomatis dan tidak menyimpulkan kerusakan dari input angka. Teks ekstraksi dapat menghilangkan layout tabel/diagram; gunakan PDF asli untuk memvalidasi urutan langkah, nilai standar, wiring diagram, dan applicability serial number. Beberapa message dalam manual hanya berisi ilustrasi/diagram dan tidak memiliki prosedur langkah lengkap.
